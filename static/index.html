METHODOLOGY
Trust the calculation.
A small, inspectable implementation keeps mathematical claims separate from protocol claims.
Objective convention
E(x) = c + xᵀQx. Every matrix entry contributes once. For asymmetric Q, Qᵢⱼ and Qⱼᵢ both contribute; reference matrices use the upper triangle only. Coefficients are finite numbers, vectors are strict binary integers, and summation uses math.fsum.
What a receipt proves
Canonical JSON is SHA-256 hashed after recomputing energy. It proves the listed inputs and value agree with this implementation. It does not prove the solver is optimal unless exact exhaustive search is used within its 16-variable limit.
Solver semantics
Random, greedy, and annealing use a specified seed. Their energy is a best observed value, not a guarantee of improvement. Runtimes are measurements on your machine and may vary.
QMS relation
QMS's published vision includes useful optimization work. Arena provides developer tooling for reproducible QUBO evaluation. Current integration reads chain identity and latest block through the official testnet RPC; local receipts are not on-chain proofs.
